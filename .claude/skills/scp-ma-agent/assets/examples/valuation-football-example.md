- Reported EBITDA: $4.4M (14.7%)

## Method A — Precedent transactions (PRIMARY)
- Foundry segment, iron, $25–50M EV → **5.4x base** (GF Data via Porter White & Co. Q1 2025).
- Premium/discount adjustments (turns of EBITDA):
  - Aero/defense exposure + low concentration: **+0.5**
  - Value-add machining + recent capex + credible #2: **+0.5**
  - Clean environmental posture: **0** (neutral protection)
- **Effective multiple: ~6.4x → $5.0M × 6.4 = ~$32.0M EV**
- Cross-check EV/Revenue: 0.9x × $30.0M = ~$27.0M (foundry benchmark — below the EBITDA-based number, suggesting the margin/lever story is doing the work)

## Method B — DCF / income approach
- WACC build: rf 4.5% + (β 1.2 × ERP 5.0%) + size premium ~5% + company-specific premium ~3% = **~18%**
- 5-yr explicit forecast; terminal Gordon growth 2.5%
- **EV range: $28–34M**

## Method C — Public-company comparables (sanity check)
- Mueller / Olympic Steel / Park-Ohio implied range, with a ~25% private-company discount applied → effective private multiple ~5.5–6.0x
- **EV: ~$28–30M**. Weight lightly — small/noisy comp set.

## Method D — LBO / PE affordability floor
- 55% senior debt at SOFR+550, 10% mezz at 12%, 35% equity
- 5-yr hold, 22% target IRR, exit at same multiple
- **Affordable EV at floor: ~$27M** — strategics with synergies should pay above this.
