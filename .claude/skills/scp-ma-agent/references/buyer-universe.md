# Buyer Universe Reference — Foundry / SCP

Build a **tiered A/B/C list**, annotated per name with fit, backing, recent
deals, and *who to call first*. The right Tier-A depends on SCP's alloy mix —
confirm ferrous vs. nonferrous vs. aerospace/investment in intake, then sequence.

**Call-order logic:**
- **Nonferrous / aluminum SCP** → call **CaneKast** and **Wisconsin Aluminum
  Foundry** first.
- **Ferrous (iron/ductile) SCP** → **Waupaca/Monomoy, Lawton Standard, Metal
  Technologies, Grede** first.
- **Aerospace / investment-casting exposure** → **CPP** and **Hitchiner** first.

Disclosure discipline: teaser (anonymized) → NDA → CIM. Phase outreach Tier A
first, monitor response, then B, then C. Never name SCP's customers pre-consent.

Data sources to build/expand the list (and to refresh — see SKILL §5): PitchBook,
S&P Capital IQ, **Grata** and **SourceScrub** (both now owned by **Datasite**,
2025), Mergermarket, Axial, Sutton Place Strategies, plus the named seeds below.
